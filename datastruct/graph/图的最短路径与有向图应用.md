## 一、最短路径问题概述

| 问题 | 目标 | 经典算法 |
|------|------|---------|
| 单源最短路径 | 一个源点到所有顶点 | Dijkstra（非负权）、Bellman-Ford（负权） |
| 全源最短路径 | 所有顶点对 | Floyd-Warshall（n 小）、n 次 Dijkstra（n 大） |

## 二、Dijkstra 算法

### 2.1 思想

与 Prim 类似，但目标是到源点的最短距离而非到集合的最小边权。

```
Dijkstra(graph, n, src):
    初始化：dist[src]=0, dist[i]=graph[src][i], visited[src]=1
    重复 n-1 次：
        取未选顶点中 dist 最小的 u
        visited[u]=1
        通过 u 松弛：dist[v]=min(dist[v], dist[u]+graph[u][v])
```

关键更新代码：

```c
if (dist[u] + graph[u][v] < dist[v])
    dist[v] = dist[u] + graph[u][v];
```

### 2.2 演示

```
图:
    0 ---2--- 1
    |         |
    1         3
    |         |
    3 ---1--- 2

从 0 出发:
  初始化: dist=[0,2,∞,1]       visited={0}
  选 3:   dist[2]=min(∞,1+1)=2 visited={0,3}
  选 1:   dist[2]=min(2,2+3)=2 visited={0,3,1}
  选 2:                          visited={0,3,1,2}

结果: 0→1=2, 0→2=2(0-3-2), 0→3=1
```

### 2.3 与 Prim 的对照

| | Prim | Dijkstra |
|--|------|----------|
| minDist 含义 | 到已选集合的最小边 | 到源点的累计距离 |
| 更新 | `min(dist, w(u,v))` | `min(dist, dist[u]+w(u,v))` |
| 区别 | 只差一个 dist[u]+ | |

理解 Prim 和 Dijkstra 长得几乎一模一样但解决不同问题，能帮你避免面试中的迷惑。

### 2.4 局限性

**不支持负权边。** 因为一旦某个顶点被标记为 visited，它的 dist 就固定了。负权边可能提供一条"绕路更短"的路径，但 Dijkstra 不会回头检查。

```
    A ---5--- B
    |         |
   -3         2
    |         |
    C ---?--- D

Dijkstra 选了 B(dist=5) 后不会再看它，
但 A→C→B = -3+2=-1 < 5！更短！
```

### 2.5 复杂度

- 朴素（数组）：O(n²)——适合稠密图
- 堆优化（优先队列）：O(e log n)——适合稀疏图

**完整代码**见 [./graph_shortest.c](./graph_shortest.c)。

## 三、Floyd-Warshall 算法

### 3.1 思想

动态规划。每次尝试用中间顶点 k 缩短路径。

```
for k = 0..n-1            // 中间顶点
    for i = 0..n-1        // 起点
        for j = 0..n-1    // 终点
            if (dist[i][k] + dist[k][j] < dist[i][j])
                dist[i][j] = dist[i][k] + dist[k][j]
```

**k 必须在最外层**，不能改在里层。

```
如果 k 在里层：每次只允许经过"一个"中间点
如果 k 在最外层：第 k 轮结束后，dist[i][j] 包含所有顶点编号 ≤ k 的路径
                （允许经过 {0,1,...,k} 中的任意顶点组合）
```

### 3.2 路径重建

```c
int next[MAXV][MAXV];  // next[i][j] = i 到 j 路径上的下一个顶点

// 初始化时：
next[i][j] = (有边) ? j : -1;

// 更新时：
if (dist[i][k] + dist[k][j] < dist[i][j]) {
    dist[i][j] = dist[i][k] + dist[k][j];
    next[i][j] = next[i][k];  // 先从 i 走到 k
}

// 重建路径：
int cur = i;
while (cur != j) {
    cur = next[cur][j];
    print(cur);
}
```

### 3.3 隐藏功能：负环检测

```c
// Floyd 结束后：
if (dist[i][i] < 0) → 存在负环
```

### 3.4 复杂度

O(n³)——n 不超过几百时可用。n 很大时改用 n 次 Dijkstra。

**完整代码**见 [./graph_shortest.c](./graph_shortest.c)。

## 四、Bellman-Ford 算法

### 4.1 思想

把所有边**松弛 n-1 次**。第 k 轮结束时，dist 包含经过 ≤ k 条边的最短路径。

```
bellmanFord(edges, e, n, src):
    1. dist[src]=0, 其余 INF
    2. 重复 n-1 次：
        对每条边 (u,v,w)：
            if dist[u]+w < dist[v]:
                dist[v] = dist[u]+w
    3. 再对所有边松弛一次：
        如果还能更新 → 存在负环
```

为什么 n-1 次？最短路径最多经过 n-1 条边（无环）。

### 4.2 演示

```
图:
    0 → 1 (5)
    0 → 2 (-2)
    1 → 2 (3)

第 1 轮: dist=[0,5,-2]
第 2 轮: 无法更新，提前结束

结果: 0→1=5, 0→2=-2
```

### 4.3 负环检测

第 n 轮还能松弛 → 存在从源点可达的负环。

```
图中有负环 1→2→3→1: 3+(-6)+2=-1<0
第 3 轮结束后再检查：
  边 3→1: dist[3]+2 < dist[1] 仍然成立
  → 负环
```

在有负环的图中，最短路径没有意义（可以无限绕圈缩短距离）。

### 4.4 复杂度

O(n·e)。适用场景：有负权边、需检测负环。

**完整代码**见 [./bellman_ford.c](./bellman_ford.c)。

## 五、最短路径算法对比

| | Dijkstra | Floyd | Bellman-Ford |
|--|----------|-------|-------------|
| 问题 | 单源 | 全源 | 单源 |
| 方法 | 贪心+松弛 | DP | 松弛 n-1 次 |
| 负权边 | ❌ | ✅（无负环） | ✅ |
| 负环检测 | ❌ | ✅ | ✅ |
| 时间 | O(n²) / O(e log n) | O(n³) | O(n·e) |
| 空间 | O(n) | O(n²) | O(n) |
| 适用 | 正权稠密/稀疏 | n 较小时的全源 | 有负权或需负环检测 |

## 六、拓扑排序

### 6.1 定义

有向无环图（DAG）顶点的线性序列，满足每条边 u→v 中 u 在 v 之前。

典型应用：编译依赖、选课安排、Makefile。

### 6.2 Kahn 算法（基于入度）

```c
topoSort(graph, n):
    统计所有顶点的入度
    将入度为 0 的顶点入队
    while 队列不空:
        u = 出队; 输出 u
        for 每个 u→v:
            indeg[v]--
            if indeg[v]==0: 入队
    如果输出的顶点数<n → 有环
```

**演示：**

```
图: 0→1→3, 0→2→3, 2→5, 3→4→5, 3→6
入度数组: [0,1,1,2,1,2,1]

队列: [0]
→ 出队 0, 入度1→0, 入度2→0 → 入队 [1,2]
→ 出队 1, 入度3→1
→ 出队 2, 入度3→0, 入度5→1 → 入队 [3]
→ 出队 3, 入度4→0, 入度6→0 → 入队 [4,6]
→ 出队 4, 入度5→0 → 入队 [5]
→ 出队 6
→ 出队 5

结果: [0,1,2,3,4,6,5]  — 7 个顶点全部输出，无环
```

### 6.3 环检测

Kahn 算法天然附带环检测。图中若有环，环上的顶点永远无法入度为 0，最终输出不足 n 个顶点。

复杂度：O(n+e)。

**完整代码**见 [./topo_critical.c](./topo_critical.c)。

## 七、关键路径（AOE 网）

### 7.1 定义

AOE（Activity On Edge）网：顶点=事件，边=活动，权值=持续时间。

**关键路径** = AOE 网中最长路径，决定项目总工期。

> 注意：这里求最长路径，不是最短路径。因为总工期取决于最长的那个依赖链。

### 7.2 四个核心概念

| 符号 | 含义 | 公式 |
|------|------|------|
| ve(v) | 事件 v 最早发生时间 | ve(v)=max(ve(u)+w(u,v)) |
| vl(v) | 事件 v 最晚发生时间 | vl(v)=min(vl(u)-w(v,u)) |
| e(a) | 活动 a(u→v) 最早开始 | e(a)=ve(u) |
| l(a) | 活动 a(u→v) 最晚开始 | l(a)=vl(v)-w(u,v) |

**关键活动**：e(a) = l(a)，时间余量为 0。必须准时开始，延迟一天工期就推一天。

**关键路径**：所有关键活动连接而成的路径。可能有多个。

### 7.3 算法

```
criticalPath(graph, n):
    1. 拓扑排序 → 获得 topo 数组
    2. 正向递推 ve：        (按 topo 顺序)
        for each u in topo:
            for each u→v:
                ve[v] = max(ve[v], ve[u]+w(u,v))
    3. 反向递推 vl：        (逆 topo 顺序)
        vl[end] = ve[end]
        for each u in 逆 topo:
            for each u→v:
                vl[u] = min(vl[u], vl[v]-w(u,v))
    4. 活动分析：
        for each edge (u,v,w):
            e = ve[u], l = vl[v]-w
            if e==l → 关键活动
```

### 7.4 演示

```
AOE 网：
  0-6→1-1→4-9→6-2→8
  0-4→2-1→4-7→8
  0-5→3-2→5-4→7

正向:
  ve[0]=0, ve[1]=6, ve[2]=4, ve[3]=5
  ve[4]=max(6+1=7,4+1=5)=7
  ve[8]=max(16+2=18,14+4=18)=18

反向:
  vl[8]=18
  vl[7]=14, vl[6]=16
  vl[4]=min(16-9=7,14-7=7)=7
  vl[1]=7-1=6, vl[0]=min(6-6=0,6-4=2,8-5=3)=0

关键活动: 0→1, 1→4, 4→6, 4→7, 6→8, 7→8
关键路径: 0→1→4→6→8 和 0→1→4→7→8
工期: 18
```

**完整代码**见 [./topo_critical.c](./topo_critical.c)。

## 八、完整算法对比总表

| 算法 | 解决什么问题 | 适用图 | 核心思想 | 时间复杂度 |
|------|------------|--------|---------|-----------|
| DFS | 连通分量、环检测 | 任意图 | 递归/栈 | O(n+e) |
| BFS | 无权最短路径 | 任意图 | 队列 | O(n+e) |
| Prim | 最小生成树 | 无向带权 | 每次取最近顶点 | O(n²) / O(e log n) |
| Kruskal | 最小生成树 | 无向带权 | 每次取最小边 | O(e log e) |
| Dijkstra | 单源最短路径 | 正权无向/有向 | 贪心+松弛 | O(n²) / O(e log n) |
| Floyd | 全源最短路径 | 任意图（无负环） | DP | O(n³) |
| Bellman-Ford | 单源最短路径 | 任意图（含负权） | 松弛 n-1 次 | O(n·e) |
| Kahn | 拓扑排序 | DAG | 入度数组+队列 | O(n+e) |
| 关键路径 | AOE 分析 | DAG（带权） | 拓扑序+DP | O(n+e) |
