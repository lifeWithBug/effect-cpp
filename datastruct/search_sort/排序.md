## 一、排序问题概述

**排序** = 将一组无序数据按关键字排列成有序序列。排序算法的核心衡量指标：

| 指标 | 含义 | 影响 |
|------|------|------|
| 时间复杂度 | 比较/交换次数随 n 增长的速度 | 决定能处理的数据规模 |
| 空间复杂度 | 额外内存消耗 | 决定内存受限场景的可用性 |
| 稳定性 | 相等元素的相对顺序是否保持不变 | 多关键字排序（先按 A 排，再按 B 排）依赖稳定性 |

排序算法的全景图：

```
排序算法
├── 简单排序 O(n²)
│   ├── 冒泡排序（相邻交换，大的上浮）
│   ├── 选择排序（每轮选最小，放到前面）
│   └── 插入排序（把元素插入到已排序序列的正确位置）
├── 高级排序 O(n log n)
│   ├── 快速排序（分治+分区，实际最快）
│   ├── 归并排序（分治+合并，稳定+保证）
│   └── 堆排序（建最大堆+取堆顶，原地但不稳定）
└── 特殊排序（后续专题）
    ├── 计数排序（整数范围小）
    ├── 桶排序（数据分布均匀）
    └── 基数排序（数的各位依次排序）
```

## 二、O(n²) 排序——简单但慢

### 2.1 冒泡排序

**核心思想**：从左往右两两比较，大的往后移。每轮结束最大的数"冒"到末尾。

**改进版**增加 `swapped` 标志：如果某一轮完全没有交换，说明已有序，提前结束。

```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int t = arr[j]; arr[j] = arr[j+1]; arr[j+1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}
```

**演示**：

```
原始:  [64 34 25 12]
第1轮: [34 25 12 64]  ← 两两比较，64 冒到最后
第2轮: [25 12 34 64]  ← 34 冒到倒数第二
第3轮: [12 25 34 64]  ← 25 到位
第4轮: 未发生交换 → 提前结束
```

**特点**：
- 唯一的价值：教学示例，展示最基本的比较和交换
- 改进版在有序数组上只需 O(n)——其他 O(n²) 排序做不到
- 10000 条数据：约 859 ms（实测最慢）

### 2.2 选择排序

**核心思想**：每轮找到剩余部分的最小值，和当前位置交换。交换次数极少（最多 n-1 次），但比较次数始终为 n(n-1)/2。

```c
void selectSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIdx]) minIdx = j;
        if (minIdx != i) {
            int t = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = t;
        }
    }
}
```

**演示**：

```
原始:  [64 34 25 12]
第1轮: min=12 → 与 64 交换 → [12 34 25 64]
第2轮: min=25 → 与 34 交换 → [12 25 34 64]
第3轮: min=34 → 已在原位 → [12 25 34 64]
```

**特点**：
- **不稳定**：可能把后面的相等元素换到前面
- 任何情况下比较次数都一样，没有最好最差之分
- 10000 条数据：约 428 ms

### 2.3 插入排序

**核心思想**：像打牌时整理手牌——每次把一张新牌插入到已排序序列的正确位置。已排序部分逐渐从左边扩展。

```c
void insertSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];  // 右移腾位置
            j--;
        }
        arr[j + 1] = key;          // 插入到空位
    }
}
```

**演示**：

```
原始:  [64 34 25 12]
  拿34 → 跟64比 → [34 64 25 12]
  拿25 → 跟64、34比 → [25 34 64 12]
  拿12 → 跟64、34、25比 → [12 25 34 64]
```

**特点**：
- **数据基本有序时接近 O(n)**——这是它最大的实际价值
- **稳定**：相等时不移动
- 三种简单排序中实际最快的
- 10000 条数据：约 262 ms

插入排序常被用作快速排序的**小规模优化**（当子数组长度小于某个阈值时改用插入排序）。

### 2.4 O(n²) 排序对比

| | 冒泡排序 | 选择排序 | 插入排序 |
|--|---------|---------|---------|
| 思路 | 相邻比较，大的上浮 | 每轮选最小值交换 | 插入到已排序位置 |
| 比较次数 | n(n-1)/2 | n(n-1)/2 固定 | n(n-1)/2 |
| 交换次数 | 最差 O(n²) | 最多 n-1 | O(n²)（仅右移赋值） |
| 最好情况 | O(n)（改进版） | O(n²) | **O(n)** |
| 最差情况 | O(n²) | O(n²) | O(n²) |
| 空间 | O(1) | O(1) | O(1) |
| 稳定性 | ✅ 稳定 | ❌ 不稳定 | ✅ 稳定 |
| 10000 实测 | 859 ms | 428 ms | 262 ms |

## 三、O(n log n) 排序——快但不完美

当 n 达到 10⁶ 量级时，O(n²) 不再可用（约 43 分钟），O(n log n) 仍能秒级完成。

### 3.1 快速排序

**核心思想**：选一个基准（pivot），把小于 pivot 的放左边、大于的放右边。然后递归排左右两边。

**三种核心操作**：

```
分区（Partition）— Lomuto 版：
  取最后一个元素为 pivot
  遍历数组，小于 pivot 的推到左边
  最后把 pivot 放到中间位置
  返回 pivot 的位置

递归：
  对 pivot 左边的子数组排序
  对 pivot 右边的子数组排序
```

```c
int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
        }
    }
    int t = arr[i+1]; arr[i+1] = arr[high]; arr[high] = t;
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low >= high) return;
    int pi = partition(arr, low, high);
    quickSort(arr, low, pi - 1);
    quickSort(arr, pi + 1, high);
}
```

**演示**（`partition([5,3,8,6,4])`，pivot=4）：

```
  索引:  0  1  2  3  4
  值:   5  3  8  6  4        pivot=4
  i=-1

  j=0: 5<4? 否 → j=1
  j=1: 3<4? 是 → i=0, swap(5,3) → [3 5 8 6 4]
  j=2: 8<4? 否 → j=3
  j=3: 6<4? 否 → 结束

  swap(5, 4) → [3 4 8 6 5]
  返回 pivot 位置: 1
```

**快排的弱点——最差情况 O(n²)**：

```
有序数组 [1 2 3 4 5 6 7]，每次选最后做 pivot:
  pivot=7 → 左边 1-6，右边空  — 极不平衡
  pivot=6 → 左边 1-5，右边空  — 以此类推
  递归深度 = n，总时间 = n²

解决方案：随机 pivot（随机选一个和最后交换）
```

**Hoare 分区**（另一种实现，实际比 Lomuto 快约 3 倍）：

```
两个指针从两端向中间靠拢：
  左指针找到 >= pivot 的元素
  右指针找到 <= pivot 的元素
  交换它们
  继续直到两指针相遇
```

### 3.2 归并排序

**核心思想**：先分到底（拆成单个元素），再两两合并成有序序列，一直合并回完整数组。

**分（Divide）**：不断从中间切分，直到只剩一个元素（天然有序）。

**治（Merge）**：两个有序子数组合并成一个更大的有序数组。

```c
void merge(int arr[], int left, int mid, int right) {
    int n1 = mid - left + 1, n2 = right - mid;
    int L[n1], R[n2];
    for (int i = 0; i < n1; i++) L[i] = arr[left + i];
    for (int i = 0; i < n2; i++) R[i] = arr[mid + 1 + i];

    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2)
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int arr[], int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}
```

**演示**：

```
[5 3 8 6 4 1 7 2]
       ↓ 分
[5 3 8 6]    [4 1 7 2]
   ↓            ↓
[5 3] [8 6]   [4 1] [7 2]
   ↓            ↓
[5][3][8][6]  [4][1][7][2]     ← 分到底，每份只有一个元素
         ↓ 合并
[3 5] [6 8]   [1 4] [2 7]
   ↓            ↓
[3 5 6 8]     [1 2 4 7]
         ↓
[1 2 3 4 5 6 7 8]             ← 合并完成
```

**特点**：
- **稳定**：合并时相等元素优先取左半边的
- **O(n log n) 保证**：没有快排的退化解
- **空间 O(n)**：合并时需要额外数组，这是最大代价
- 常用于**外部排序**（磁盘数据处理）：只需顺序读写

### 3.3 堆排序

**核心思想**：利用**完全二叉树**和**最大堆**性质，每次取堆顶（最大值）放到数组末尾。

**堆**是一种特殊的完全二叉树：父结点的值 ≥ 子结点的值（最大堆）。

```
      10              数组表示: [10, 7, 8, 5, 3, 6, 4]
     /  \
    7    8            对于下标 i：
   / \  / \           父结点: (i-1)/2
  5  3 6  4           左孩子: 2i+1, 右孩子: 2i+2
```

**堆排序的两个阶段**：

```c
void heapify(int arr[], int n, int i) {
    int largest = i;
    int l = 2 * i + 1;
    int r = 2 * i + 2;
    if (l < n && arr[l] > arr[largest]) largest = l;
    if (r < n && arr[r] > arr[largest]) largest = r;
    if (largest != i) {
        int t = arr[i]; arr[i] = arr[largest]; arr[largest] = t;
        heapify(arr, n, largest);
    }
}

void heapSort(int arr[], int n) {
    // 阶段 1：建堆 O(n)
    for (int i = n/2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // 阶段 2：排序 O(n log n)
    for (int i = n - 1; i > 0; i--) {
        int t = arr[0]; arr[0] = arr[i]; arr[i] = t;  // 堆顶→末尾
        heapify(arr, i, 0);                             // 调整堆
    }
}
```

**阶段 1 演示**（建堆）：

```
原始: [3, 7, 8, 5, 1, 6, 4]
              堆化前              堆化后
       3                  8
     /   \              /   \
    7     8      →     7     6
   / \   / \          / \   / \
  5  1  6   4        5  1  3   4
```

**阶段 2 演示**（排序）：

```
堆: [8, 7, 6, 5, 1, 3, 4]
取堆顶 8 放末尾 → 堆变成 [7, 5, 6, 4, 1, 3] | [8]
取堆顶 7 放末尾 → 堆变成 [6, 5, 3, 4, 1]    | [7, 8]
取堆顶 6 放末尾 → 堆变成 [5, 4, 3, 1]       | [6, 7, 8]
...
最终: [1, 3, 4, 5, 6, 7, 8]
```

**特点**：
- **O(n log n) 保证**，没有退化解
- **原地排序**（空间 O(1)）
- **不稳定**
- 20000 条数据：约 4 ms。比快排稍慢，但比归并省空间

### 3.4 O(n log n) 排序对比

| | 快速排序 | 归并排序 | 堆排序 |
|--|---------|---------|--------|
| 分治策略 | 分区后递归 | 分到底再合并 | 建堆后取堆顶 |
| 最好 | O(n log n) | O(n log n) | O(n log n) |
| 最差 | **O(n²)**（退化） | O(n log n) | O(n log n) |
| 平均 | O(n log n) | O(n log n) | O(n log n) |
| 空间 | O(log n) | **O(n)** | **O(1)** |
| 稳定性 | ❌ 不稳定 | ✅ **稳定** | ❌ 不稳定 |
| 20000 实测 | 3 ms | 5 ms | 4 ms |
| 主要弱点 | 可能退化 | 占内存 | 常数大、不稳定 |

## 四、排序算法全景总表

| 算法 | 最好 | 最差 | 平均 | 空间 | 稳定 | 一句话 |
|------|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ | 改进版在有序时提前结束 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ | 交换次数最少，但始终一样 |
| 插入排序 | **O(n)** | O(n²) | O(n²) | O(1) | ✅ | 基本有序时最快 |
| 快速排序 | O(n log n) | **O(n²)** | O(n log n) | O(log n) | ❌ | 实际最快的通用排序 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✅ | 稳定且保证，但占内存 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | **O(1)** | ❌ | 原地且保证，常数稍大 |

## 五、如何选择排序算法

```
数据很少（n < 100）？
  → 插入排序（最简单，常数极小）
数据基本有序？
  → 插入排序（接近 O(n)）
数据很大（n > 10⁶）？
  → 快速排序（默认选择）
  → 归并排序（如果必须稳定）
  → 堆排序（如果内存极度紧张）
需要稳定排序？
  → 归并排序
需要原地排序（空间 O(1)）？
  → 堆排序
数据有特殊性质？
  → 整数且范围小 → 计数排序 O(n)
  → 均匀分布 → 桶排序 O(n)
  → 整数可拆位 → 基数排序 O(n)
```

**工程中的默认选择**：大多数语言的默认排序是**快速排序的变体**（C 的 qsort、C++ 的 sort），但 Java 的 `Arrays.sort` 对对象使用归并排序（需要稳定），对基础类型使用快速排序。Python 使用 TimSort（归并+插入的混合体）。
